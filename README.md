# 📊 Simulador de Investimentos em Fundos Imobiliários

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de **Excel**, com o objetivo de aplicar conceitos de planilhas e cálculos financeiros na criação de uma ferramenta de **simulação de investimentos em Fundos de Investimento Imobiliário (FIIs)**.

A ferramenta permite que o usuário informe diferentes parâmetros relacionados aos seus investimentos e visualize uma projeção de sua evolução ao longo do tempo.

O simulador realiza automaticamente cálculos como:

* 💰 Valor total investido;
* 📈 Patrimônio acumulado;
* 💵 Dividendos mensais estimados;
* 📊 Evolução do investimento ao longo do tempo;
* ⏳ Projeção de resultados de acordo com o período definido.

A proposta é facilitar a compreensão do impacto dos aportes e dos rendimentos no crescimento do patrimônio, proporcionando uma visão mais clara dos possíveis resultados de uma estratégia de investimento.

> **Observação:** Os resultados apresentados pela ferramenta são projeções baseadas nos valores informados pelo usuário e não representam garantia de rentabilidade futura.

---

## 🎯 Objetivos

O projeto tem como principais objetivos:

* Desenvolver uma ferramenta prática de simulação de investimentos utilizando Excel;
* Aplicar conceitos de matemática financeira;
* Automatizar cálculos relacionados a investimentos;
* Demonstrar o impacto dos aportes mensais e dos juros compostos;
* Estimar o recebimento de dividendos;
* Facilitar a análise de diferentes cenários de investimento;
* Documentar o desenvolvimento do projeto utilizando o GitHub.

---

## 🛠️ Tecnologias utilizadas

* **Microsoft Excel** — desenvolvimento da ferramenta e realização dos cálculos;
* **GitHub** — armazenamento e documentação do projeto;
* **Markdown** — elaboração da documentação.
